# 晴天娃娃 · 项目文档索引

Windows 桌面挂件：鼠标指针下方悬挂一个晴天娃娃（当前用 🧸 占位），跟随鼠标摇晃。
手感可以随时调：按 `Ctrl+Alt+S` 打开设置面板，拖滑块即时生效。

> **重要**：所有回复与文档使用**中文**。本项目不使用英文文档。

## 30 秒上手

```powershell
cd "F:\study\DeepSeekHarness\test_1\晴天娃娃\v0"
node rope.test.cjs          # 回归测试，应输出「全部通过 ✓」
node verify.cjs             # 验收测量，输出 11 组基线指标
.\启动晴天娃娃.bat           # 启动挂件
```

- 退出：`Ctrl + Alt + Q`
- 显隐：`Ctrl + Alt + H`
- **设置面板：`Ctrl + Alt + S`，或托盘图标右键 → 「设置…」**（7 个档位选中后点「应用」生效；滑块拖动即时生效）
- 托盘右键 → **「档位」** 子菜单可直接换档，不用开面板
- 改配置后：托盘图标右键 → **重载配置**（无需重启）

## 三个最容易踩的坑（不读文档必踩）

### 1. 测试时必须有真实鼠标干扰的意识

指针有 3 路输入源在竞争：真实 `mousemove`、主进程 8ms 轮询、脚本注入。
手动改坐标会被轮询覆盖回真实位置。

**验证物理逻辑请用纯 Node 测试，不要依赖窗口截图。**
详见 [03-测试方法论](03-测试方法论.md) 铁律 1。

### 2. 退出走程序自己的路径

用托盘「退出」/ `Ctrl+Alt+Q` / `启动晴天娃娃.bat`。

**第 11 轮起这条约束的技术原因已经消失**：旧版用 koffi 调 Win32 `ShowCursor` 改全局/线程指针显示计数，强杀会绕过 `will-quit` 里的恢复钩子、让系统指针永久消失。现在整个 `system-cursor.js` 与 koffi 依赖都已删除，程序对系统指针**无任何全局副作用**，强杀只会留下进程。仍建议优雅退出，是为了不留 electron 残留。

### 3. PowerShell 按行改 JS 极易错位

必须用 `[System.IO.File]::ReadAllLines` + 按索引替换 +
`WriteAllLines(UTF8Encoding($false))`，改完立刻 `node --check` 并回读确认。
已因这个操作产生过 5 次 `SyntaxError` 和 1 次「小熊整个消失」。
`.Replace()` 改多行代码会因 CRLF 差异**静默失败**。
